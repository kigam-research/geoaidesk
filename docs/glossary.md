# GAID terminology

| 한국어 용어 | English term | 정의 | 피할 말 |
|---|---|---|---|
| Workflow | Workflow | 연구 작업 하나를 AI agent에게 맡기는 절차입니다. 입력 자료, 연구자가 정할 조건, 단계, AI agent 지시문, 사용하는 스킬, 결과와 해석 한계로 이루어집니다. | 허브 단위의 방법 |
| 스킬 | skill | Workflow가 쓰는 지침과 도구 꾸러미입니다. 기본 제공 스킬, GitHub 등에서 가져온 스킬, Workflow에 딸린 스킬, 허브 스킬이 있습니다. | — |
| 허브 스킬 | hub skill | GAID 허브의 스킬 선반에 version마다 사본으로 올린 스킬입니다. 출처, 라이선스, 검토 상태를 함께 기록하고, 여러 Workflow가 version을 고정해 씁니다. 스킬 version은 1, 2, 3처럼 정수입니다. | — |
| version | version | 허브에 Workflow를 등록할 때마다 붙는 번호입니다. 처음 등록하면 0.1.0이고, 다시 등록할 때 등록한 연구자가 patch(0.1.0 → 0.1.1), minor(0.1.x → 0.2.0), major(정식 배포 1.0.0, 이후 2.0.0) 가운데 고릅니다. 초안에는 version이 없고 초안으로 표시합니다. 한국어 화면에서도 영어 단어 version을 씁니다. | 판, 버전 |
| 저장한 시작 설정 | saved start settings | Workflow의 입력과 조건 값을 미리 정해 둔 것입니다. | 레시피 (연구 기능 제외) |
| 기본 Workflow | built-in Workflow | GAID와 함께 배포되는 Workflow입니다. | — |
| 일반 Workflow | general Workflow | 단계와 스킬 없이 지시문으로 시작하는 Workflow입니다. | — |
| 예제 자료 | example data | Workflow가 입력마다 함께 제공하는 자료입니다. 연구자가 자기 파일을 고르지 않으면 이 자료로 분석을 시작하고, 지침과 결과에 예제 자료로 실행했다고 적습니다. 작은 자료는 Workflow에 들어 있고, 큰 자료는 처음 쓸 때 공개 주소에서 받아 해시를 확인합니다. 시뮬레이션으로 만든 자료는 합성 자료로 표시합니다. | 샘플 데이터, 예시 데이터 |
| Workflow 시작 창 | Workflow start window | Workflow를 고르면 열리는 하나의 창입니다. Workflow 소개, 입력 자료, 분석 조건, 요약 순서로 진행하고 마지막에 새 채팅에 시작 초안을 만듭니다. 기본 Workflow, 허브 Workflow, 일반 Workflow가 모두 이 창을 씁니다. | 시작 대화상자, 실행 창 |
| 내 자료 / 이전 결과 | your data / earlier results | 입력 파일 후보를 나누는 두 묶음입니다. 프로젝트의 `user_data/` 아래 파일이 내 자료이고, 그 밖의 파일(이전 분석의 결과, 연구노트 그림 등)이 이전 결과입니다. | 원본, 산출물 (이 구분에서) |
| 폴더 (서재) | library folder | 서재의 논문을 주제나 원고별로 묶는 곳입니다. 하위 폴더를 둘 수 있고, 한 논문이 여러 폴더에 들어갈 수 있습니다. Zotero 컬렉션과 이어질 수 있습니다. | 모음, 컬렉션 (GAID 쪽 이름으로) |
| 내 논문 (서재) | own works | 연구자가 ORCID 기록에서 자기 논문으로 확인해 표시한 서재 논문입니다. 서재의 "내 논문" 보기에서 모아 봅니다. 연결된 ORCID iD와 그 기록 안의 논문 번호가 함께 남습니다. | 내 성과, 내 업적 |
| 정리 노트 (서재) | research note (library) | 서재에 넣은 정리 노트입니다. 논문과 다른 종류로 나뉘어 따로 보고, 폴더에 넣고, 프로젝트에서 다시 엽니다. 노트 파일이 원본이며 서재는 제목, 상태, 인용한 논문과 본문 앞부분을 파일에서 읽어 갱신합니다. Zotero에는 쓰지 않습니다. | 노트 논문, 노트 항목
| 인용 범위 | citation scope | 프로젝트에 붙인 폴더(하위 폴더 포함)와 논문입니다. AI agent와 연구노트 인용 점검이 이 범위 밖 인용을 따로 표시합니다. | — |
| GAID 허브 서버 | GAID hub server | 여러 연구자의 GAID가 함께 쓰는 원내 서버입니다. 계정, 공유 허브(등록된 Workflow, version, 폴더, 별, 댓글)와 계정별 서재 동기화를 맡습니다. AI agent, 명령 실행, 프로젝트는 없습니다. | 공유 GAID, 중앙 GAID |
| 그림 기록 | figure record | 정리 노트에 든 그림 한 장의 종류, 그린 채팅·스크립트·자료, 그 뒤에 바뀌었는지, 목표 저널 점검 결과, AI 그림의 공개 문구 초안을 모아 보여 주는 곳입니다. 분석 계보에서 계산하며 따로 저장하지 않습니다. | 그림 이력 |
| 그림 점검 | figure check | 목표 저널의 그림 요건(폭, 해상도, 최소 글자 크기, 파일 형식, 색, AI 그림 정책)과 그림 파일을 비교한 결과입니다. 규정 충족을 뜻하지 않습니다. | 규정 검증, 적합 판정 |
| 연결 지도 | connection map | 고른 항목(논문, 정리 노트, 그림, 파일, 채팅, Workflow) 둘레의 연결을 보여 주는 화면입니다. GAID가 이미 기록한 연결만 씁니다. | 인용 지도 |
| 결과 묶음 | result bundle | 정리 노트 하나를 다른 연구자나 심사자가 확인할 수 있도록 내려받는 ZIP 파일입니다. 노트 본문과 그림, 노트를 쓴 채팅이 읽거나 만든 자료의 지문(sha256), 환경 기록, Workflow version과 지침, 인용 논문 목록이 들어 있습니다. 자료 파일은 넣지 않으며, 결과를 다시 실행했다는 증명이 아닙니다. | 증거 패키지 (노트 기능에서), 재현 패키지 |
| 공개 자료 내보내기 | public material export | 연구자가 Gemini Notebook 같은 외부 서비스에 직접 올릴 파일을 고르는 기능입니다. 정리 노트(Markdown), Workflow 지침(Markdown), 인용 논문 PDF 가운데 파일마다 "기관 밖으로 내보내도 되는 자료"로 확인한 것만 묶습니다. GAID는 외부 서비스에 아무것도 보내지 않습니다. | 업로드, 동기화 |
