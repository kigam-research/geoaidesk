# GAID terminology

| 한국어 용어 | English term | 정의 | 피할 말 |
|---|---|---|---|
| Workflow | Workflow | 연구 작업 하나를 AI agent에게 맡기는 절차입니다. 입력 자료, 연구자가 정할 조건, 단계, AI agent 지시문, 사용하는 스킬, 결과와 해석 한계로 이루어집니다. | 허브 단위의 방법 |
| 스킬 | skill | Workflow가 쓰는 지침과 도구 꾸러미입니다. 기본 제공 스킬, GitHub 등에서 가져온 스킬, Workflow에 딸린 스킬, 허브 스킬이 있습니다. | — |
| 허브 스킬 | hub skill | GAID 허브의 스킬 선반에 판마다 사본으로 올린 스킬입니다. 출처, 라이선스, 검토 상태를 함께 기록하고, 여러 Workflow가 판을 고정해 씁니다. | — |
| 저장한 시작 설정 | saved start settings | Workflow의 입력과 조건 값을 미리 정해 둔 것입니다. | 레시피 (연구 기능 제외) |
| 기본 Workflow | built-in Workflow | GAID와 함께 배포되는 Workflow입니다. | — |
| 일반 Workflow | general Workflow | 단계와 스킬 없이 지시문으로 시작하는 Workflow입니다. | — |
| 폴더 (서재) | library folder | 서재의 논문을 주제나 원고별로 묶는 곳입니다. 하위 폴더를 둘 수 있고, 한 논문이 여러 폴더에 들어갈 수 있습니다. Zotero 컬렉션과 이어질 수 있습니다. | 모음, 컬렉션 (GAID 쪽 이름으로) |
| 인용 범위 | citation scope | 프로젝트에 붙인 폴더(하위 폴더 포함)와 논문입니다. AI agent와 연구노트 인용 점검이 이 범위 밖 인용을 따로 표시합니다. | — |
