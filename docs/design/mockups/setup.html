분석할 레이어 선택

지도와 면적 표에 사용할 파일을 고르세요.

범주 지도·좌표계·면적 표 스킬이 꺼져 있고 GeoPandas 환경이 준비되지 않았습니다.

지원 형식과 점검 범위 보기

지원 형식: Shapefile, GeoPackage, GeoJSON, GeoTIFF. 벡터와 래스터의 CRS·범위·속성을 점검합니다.

관심 지역 선택

지도를 표시하고 면적을 계산할 범위를 정하세요.

범주 속성 열 선택

지도 색과 면적 표를 나눌 기준입니다.

면적 계산 방법 선택

계산 방법에 따라 면적이 달라집니다. 방법과 단위를 표에 기록합니다.

원본 CRS 확인

CRS를 확인하지 않은 파일입니다. 원본 자료의 CRS와 근거를 입력하세요.

면적 계산과 CRS 조건 보기

경위도 좌표로 평면 면적을 재지 않습니다. CRS 정보가 없거나 충돌하면 근거가 있는 사용자 지정 값을 먼저 확인합니다.

선택 내용 확인

새 채팅에 시작 초안을 만듭니다. 메시지는 전송하지 않습니다.

선택한 조건은 미시험입니다. 결과는 검토 전입니다.

예상 결과와 한계 보기

좌표계·범위·속성 목록, 범주 지도, 요청한 범주별 면적 표와 실행 기록을 만듭니다.

지도 표시와 면적 계산까지입니다. 좌표계를 추정하지 않고, 표시 CRS로 원본을 바꾸지 않으며, 지질 해석은 하지 않습니다.
