Workflow와 레시피 자세히

PU 학습·공간 블록 CV·컨포멀 구역화 탐사 유망도 Workflow

바리오그램 기반 블록 크기 제안 → 사용자 확인 → 전처리 확인 → 중첩 공간 CV → XGBoost/BaggingPU-XGBoost 학습 → 부트스트랩 pIQR → 크로스-컨포멀 보정 → 5구역 할당

선택 조건: 크로스-컨포멀 구현 방식, 구역 lift 백분위 경계, pIQR 불확실성 컷오프, 최소 양성 샘플 수, 변수별 전처리.

선택 입력: 전처리 설정. 예상 결과에는 포획·커버리지·구역 통계 보고서와 바리오그램 분석 결과도 포함됩니다.

해석 한계 자세히

결과는 새 지역 그리드 데이터에 대한 통계적 유망도 구역화이며, 광상의 존재를 보장하지 않습니다. 단일 크라톤(Yilgarn) Ni에서 검증된 방법의 전이이며, 다른 지질 환경에서의 성능은 미검증입니다. pIQR은 모델 불안정성만 정량화하며 레이블 모호성·구조적 불확실성을 포함하지 않습니다. 컨포멀 커버리지는 교환성 가정 하의 유한표본 보정이며 공간 자기상관에서 엄밀히 성립하지 않습니다.
