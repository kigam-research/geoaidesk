# 로컬 모델 최소 컨텍스트와 지출 한도 처리 보완

## 0. 한눈에

| 항목 | 내용 |
|---|---|
| 요청 | 이미 선택한 권장안 중 최소 컨텍스트 안내와 로컬 과금 처리 보완 |
| 결론 | 새 로컬 설정은 64K 이상을 사용하며, 지출 한도를 넘긴 프로젝트도 로컬 대화와 로컬 하위 에이전트를 실행할 수 있도록 수정했습니다. |
| 믿을 수 있는 정도 | 설정·과금 회귀 시험과 전체 자동 검사의 각 단계를 통과했습니다. 실제 모델로 연구 과제를 수행하는 시험은 이번 범위가 아닙니다. |
| 결정할 일 | 없음 |

## 1. 요청한 것

> "gaid-runtime#1을 포함하여 #1,2,3,4 모두 권장안으로 진행하자." — 2026-10-11 요청

이번 작업의 완료 기준은 32K 제안 프로필을 제거하고 최소 64K를 안내하며, 전용 로컬 모델을 비용 0의 일반 유료 모델이 아닌 로컬 실행으로 분류하는 것입니다. 배포용 카탈로그와 실제 과제 시험은 별도 출시 검증 작업에 남깁니다.

## 2. 수행한 것

1. 설정 화면의 기본 컨텍스트와 새로 저장할 수 있는 최소값을 65,536 토큰으로 맞췄습니다. 기존에 저장한 작은 컨텍스트는 자동으로 덮어쓰지 않습니다.
2. 32K 제안 프로필을 제거했습니다. 64K는 아직 시험하지 않은 제안이며, 98,304 토큰의 기존 기록은 한 기기에서 수행한 시험이라는 구분을 유지했습니다.
3. 전용 로컬 모델의 대화, 하위 에이전트, 사용량 기록, 모델 선택 화면에 같은 로컬 과금 분류를 적용했습니다.

## 3. 결과

| 완료 기준 | 결과 |
|---|---|
| 최소 컨텍스트 안내 | 64K를 기본값과 최소값으로 적용하고 32K 제안 프로필을 제거했습니다. |
| 지출 한도 초과 시 로컬 실행 | 전용 로컬 모델을 지출 한도에서 제외하도록 수정했습니다. |
| 다른 모델의 과금 유지 | 일반 사용자 정의 서버는 단가가 0이어도 유료 과금 분류를 유지합니다. 유료 도구와 유료 하위 에이전트는 계속 한도를 적용받습니다. |
| 기존 설정 보존 | 이전 설정은 그대로 표시하며 새로 저장할 때 최소값을 적용합니다. |

그림 없음: 설정값과 과금 분류를 보완한 작업으로, 판단에 필요한 결과를 표로 제시했습니다.

## 4. 검증

- 관련 회귀 시험 54개를 통과했습니다. 지출 한도 초과 상태의 로컬 대화·하위 에이전트 실행, 사용량 기록, 일반 사용자 정의 서버의 유료 분류 유지, 최소 컨텍스트 검증을 포함합니다.
- 백엔드 타입 검사와 전체 시험 1,582개를 통과했습니다. 11개는 제외되었으며, 이 중 2개는 네트워크에서 외부 어휘 파일을 받을 수 없어 검사 스크립트가 제외한 항목입니다.
- 프런트엔드 시험 898개와 배포 구성 시험 11개를 통과했습니다. 분석 보조 환경과 새 분석 환경의 필수 모듈 가져오기 검사, 두 실행기의 의존성 검사도 통과했습니다.
- 빈 데이터 폴더에서 앱을 시작하고 재시작하는 검사를 통과했습니다. 프로젝트·파일 보존, 고정 카탈로그 설치, 제외된 문서 스킬의 부재, 추적 파일 불변을 확인했습니다.
- 다른 작업의 최신 변경을 합친 상태에서도 백엔드 시험 1,585개와 프런트엔드 시험 901개가 각각 통과했습니다. 프런트엔드 재검사는 동시 실행 수를 줄여 수행했습니다.
- 전체 검사 단계가 개별 실행에서 통과했습니다. 최종 통합 시 동일한 필수 검사 전체를 다시 실행하며, 통합 결과는 작업 완료 수령증에 기록합니다.
- 실제 모델을 호출하지 않았습니다. 자동 시험은 모델의 연구 수행 능력이나 메모리 여유를 검증하지 않습니다.

## 5. 한계

- 실제 로컬 모델의 성능, 메모리 사용량, 64K·98,304 토큰에서의 연구 과제 성공 여부는 검증하지 않았습니다. 이는 별도 출시 검증 작업의 범위입니다.
- 이번 변경은 전용 로컬 모델 설정에 적용합니다. 기존 일반 로컬 서버 연결의 컨텍스트 선언값이나 과거 비용 기록을 일괄 변경하지 않습니다.
- 별도 운영 서비스에 배포하지 않습니다.

## 7. 대체되었거나 실패한 시도

- 검사 스냅샷 생성이 기존 환경 예제 파일의 경로를 금지 경로로 분류하여 중단되었습니다. 검사 프로세스는 시작되지 않았습니다. 해당 파일을 읽거나 바꾸지 않고 작업 관리 도구의 검사·통합 경로를 사용했습니다.
- 처음 추가한 대화 시험은 사용량을 0토큰으로 보고하여 비용 기록 확인에 실패했습니다. 시험 데이터를 고친 뒤 관련 시험 54개가 모두 통과했습니다.
- 수정 책임자 메타데이터에 작업 단위 이름을 적어 배포 구성 검사가 거부했습니다. 허용된 상위 패키지 이름으로 고친 뒤 11개 검사를 통과했습니다.
- 첫 시작·재시작 검사 중 작업 문서를 갱신하여 추적 파일 불변 검사가 실패했습니다. 문서 갱신 없이 재실행하여 통과했습니다.
- 최신 변경을 합친 후 기존 문서 편집기 시험이 시간 제한을 넘겼습니다. 동시 실행 수를 줄이면 프런트엔드 전체가 통과했습니다. 이 설정을 전체 검사에 적용하면서 백엔드의 직렬 실행을 덮어쓴 실수도 확인했습니다. 제품 코드를 바꾸지 않고 전체 검사를 단일 작업자로 실행하도록 설정했습니다.
- 이전 실행 기반 보고서의 로컬 과금 한계와 최소 컨텍스트 결정 중 이번 작업에 해당하는 두 항목을 해결합니다. 나머지 결론은 변경하지 않습니다.
