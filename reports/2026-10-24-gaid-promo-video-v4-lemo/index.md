# GAID 홍보 영상 lemo판: v4 메시지를 발표 영상 스타일로 다시 만든 102초 영상과 40초 영상 (내부 검토용, 음악·효과음)

## 0. 한눈에

| | |
|---|---|
| 요청 | lemo-opuscar에서 GAID 허브 홍보에 맞는 스타일을 골라 v4 메시지로 영상을 만듭니다. 작업 중에 40초 홍보판을 하나 더 만들고, 두 예제를 쓰고, 실제 화면을 모션그래픽 속 창으로 보여 달라는 요청이 더해졌습니다. |
| 결론 | 102.3초 영상을 만들었습니다. 1920×1080, 30fps, 스테레오 음악·효과음이고 음량은 −14.1 LUFS입니다. 40초판은 하위 작업이 만들고 있으며, 끝나면 이 보고서 8절에 결과를 더합니다. |
| 믿을 수 있는 정도 | 실제 화면은 v2·v3 때 GAID에서 촬영한 것이고 화면 문구는 바꾸지 않았습니다. 배경, 연구 순환, Second brain 장면은 설명 그림입니다. 음량과 빈 화면은 완성 파일에서 측정했고, 소리는 측정값과 파형으로만 확인했습니다(5절). |
| 결정할 일 | 없음. 영상 검토 의견을 받습니다. |

## 1. 요청한 것

> V4와 병렬로 진행가능하면 brag 영상 작업시작하자. 그리고 또 별도로 https://github.com/lemomo-ai/lemo-opuscar 에서 GAID 허브 시스템 홍보에 적합한 것을 선정해 brag영상 제작작업과 동일한방식으로 lemo작업도 시작하자. — 2026-10-24 요청

> 메시지는 동등해도 되는데 연출은 오히려 더 자유롭게 홍보성으로 만들자. 그리고 분량은 40초로하고 코드로 된 영상 기반으로 전면 새로 만들어도 좋다. 현재 촬영자료가 있다고 너무 v4스타일로 만들필요는없다. 현재 렌더링중인것은 계속만들고 별도로하나더 생성하자. — 2026-10-24 작업 중 요청

> 예제도 yilgarn예제와 PGI예제를 둘다써도되고 꼭 모든 워크플로우가 하나의 예제만 보이는것이 아니라 적합한것을 사용하고 촬영 에셋이 영상 전 영역을 차지하지 않고, 해당 기능을 소개하는 모션그래픽속의 창요소처럼 보여도되므로 상품성 높은 홍보영상으로 제작하자. — 2026-10-24 작업 중 요청

"동일한 방식"은 brag판에 정한 조건입니다. 메시지는 v4와 같고, 90~105초, 음악과 효과음만 쓰고 내레이션은 없으며, 내부 검토용이고, v4를 대체하지 않고 나란히 둡니다.

완료 기준은 다음과 같습니다.
- 스타일 후보 2~3개를 보여 드리고 하나를 고릅니다.
- v4 이야기를 그 스타일로 다시 만듭니다. 1920×1080, 30fps, 스테레오 음악과 효과음, 90~105초입니다.
- 40초 홍보판을 따로 만듭니다.
- GAID 규칙을 지킵니다. 화면 이름은 "AI agent"와 "GAID"로 쓰고, 만든 숫자와 독점 자산·글꼴을 쓰지 않으며, "개념도" 같은 모서리 표시를 넣지 않습니다.

## 2. 수행한 것

1. lemo-opuscar(커밋 3961ddb)를 받아 59개 스타일을 검토했습니다. 후보 세 개를 작업 탭과 검토용 사본에 포스터와 함께 보여 드렸습니다.
   - Dark Tech Keynote(선택): 소프트웨어 발표 영상의 문법입니다. "흩어진 것이 한 번의 동작으로 격자에 모인다"는 이 스타일의 기본 장면이 v4 배경 이야기와 같습니다. 강조색 하나를 GAID 파랑으로 쓰고, 소리도 흩어진 음에서 한 조성의 음으로 모입니다.
   - Swiss Motion Graphics: GAID의 도폭 스타일과 가깝지만, v4가 이미 밝고 평평한 화면이라 차이가 작습니다.
   - Living Screencast: 화면 녹화 문법이지만 픽셀 마스코트와 UI를 새로 그리는 것이 핵심이어서 실제 촬영본과 맞지 않습니다.
2. 연출안을 먼저 썼습니다. 구조 후보 세 개 중 "흩어짐 → 멈춤과 클릭 → 격자로 모임 → 순환"을 골랐습니다. 장면 목록, 박자 지도(120 bpm), 소리 설계표를 함께 정했습니다.
3. 장면을 코드로 그렸습니다. 배경은 GAID 어두운 화면 색이고, 글꼴은 Pretendard 하나입니다. 로고의 궤도 고리가 커져 연구 순환이 되는 장면을 이 영상의 대표 장면으로 넣었습니다.
4. 세 번째 요청에 따라 시연 구간을 다시 짰습니다.
   - 실제 화면은 오른쪽 창에 한 배율로 보여 줍니다. 창 안을 확대하거나 스크롤하지 않습니다.
   - 왼쪽에는 GAID 허브/GAID 시스템 표시, 목적 문장, 그 장의 기능 목록이 쌓입니다. 지금 설명하는 기능은 선으로 화면의 파란 상자와 이어집니다.
   - 포천 자철석 예제(v3 촬영본)에 Yilgarn 니켈 탐사 예제(v2 촬영본)의 지도, 연구노트, 연결 지도 장면을 더했습니다. 창 위의 표시가 어느 예제인지 알려 줍니다.
5. 음악과 효과음을 영상의 동작 목록에서 만들었습니다. 음악은 D 리디안 조성의 새 곡이고, 악기는 마림바, 비브라폰, 글로켄슈필 같은 공개(CC0) 샘플입니다. 효과음은 코드로 합성했습니다. 멈춤 장면은 완전한 무음이고, Second brain 앞에는 거의 무음인 0.5초를 두었습니다.
6. 미리보기 영상을 전체 렌더해 1초 간격 정지 화면과 클릭 장면의 0.2초 간격 프레임을 확인했습니다. 저음 과다와 음량 미달을 고친 뒤 최종 영상을 렌더했습니다.
7. 40초판은 하위 작업에 맡겼습니다. 두 번째·세 번째 요청을 그대로 전달했습니다.

## 4. 검증

- 과학적 검증: 해당 없음. 시연에 나오는 분석은 v2·v3 때 예제 자료로 한 홍보용 실행입니다.
- 영상: 완성 파일을 다시 읽었습니다. 102.3초, 3,069프레임, 1920×1080, 30fps, H.264입니다. 검은 화면 검사에서 걸린 구간은 없습니다. 렌더 중 브라우저 오류는 없었습니다(있으면 렌더가 실패합니다).
- 소리: 완성 파일의 음량은 −14.1 LUFS, 최대치 −1.3 dB, 음량 범위 5.0 LU입니다. 첫 믹스는 저음(20–120 Hz)이 나머지 대역보다 컸고 제목 구간이 10 dB 이상 작아서 고쳤습니다. 최종 믹스에서 저음은 나머지 대역보다 4.7 dB 작습니다. 멈춤 구간의 신호가 0인 것을 확인했습니다.
- 장면: 미리보기의 1초 간격 정지 화면 102장과 클릭 장면(9.4~12.6초)의 0.2초 간격 프레임을 눈으로 봤습니다. 겹침, 잘림, 빈 화면이 없었습니다.
- 읽는 시간: 화면 글 44개 중 17개가 lemo의 읽기 시간 기준(한글 4.5자/초 + 1.5초)보다 짧습니다. 대부분 기능 목록 항목과 순환 장면 이름표이고, 한 번 나타난 뒤 장이 끝날 때까지 남습니다. 가장 짧은 것은 기능 목록의 "원본 값을 바로 확인"(1.9초)과 Second brain의 두 문장(2.8초, 3.3초)입니다(5절).
- 검토용 앱: 쓰지 않았습니다. 새로 촬영하지 않았습니다.

## 5. 한계

- 내부 검토용입니다. 기관 로고는 쓰지 않았고, 외부 공개 승인은 따로 필요합니다(gaid-release-proof#2).
- 설명 그림: 흩어짐, 모임, 연구 순환, Second brain 장면은 실제 화면이 아닙니다. 도구와 파일 이름은 실제 이름이고, 수치는 넣지 않았습니다.
- 소리는 측정값과 파형으로만 확인했습니다. 이 작업 환경에서는 소리를 직접 들어 보지 못했습니다. 검토하실 때 소리 균형 의견을 주시면 반영합니다.
- 길이를 맞추느라 Second brain 문장 두 개가 2.8초와 3.3초만 보입니다. 끝까지 읽기 빠듯할 수 있습니다.
- 스타일에서 벗어난 점: Dark Tech Keynote 원문은 실제 앱 화면을 쓰지 않지만, 이 영상은 실제 촬영본을 창으로 넣었습니다. 원문의 Inter·JetBrains Mono 대신 Pretendard를 썼습니다.
- 장면 순서는 v4와 같아서 허브 공유(version 0.1.1 등록)가 분석보다 먼저 나옵니다. 실제로는 0.1.0으로 분석한 뒤 0.1.1을 등록했습니다.
- 분석 결과의 한계는 v2·v3 보고서와 같습니다. 포천 노트는 "검토 전" 상태이고, Yilgarn 탐사 우선순위는 광상 존재 확률이 아닙니다(화면의 노트에도 적혀 있습니다).
