# GAID 홍보 영상 v4_brag: brag 스킬로 다시 만든 소리 있는 101초 영상 (내부 검토용)

## 0. 한눈에

| | |
|---|---|
| 요청 | brag 스킬을 도입해 v4와 같은 메시지로, 소리까지 넣은 홍보 영상 v4_brag를 만듭니다. |
| 결론 | 100.8초 영상을 만들었습니다. 화면 문구와 실제 앱 촬영본은 v4와 같고, 장면 길이와 순서만 brag 규칙에 맞게 다시 짰습니다. 음악과 효과음은 코드로 합성한 스테레오 한 곡입니다. |

## 1. 요청한 것

> 사용자는 현재 v4 영상 작업이 완료되면 https://github.com/latent-spaces/brag를 도입하고 사용하여 v4_brag로 소리까지 포함된 홍보영상을 생성하고싶다. 주요 메시지는 v4와 동등하게 하면서 brag스킬로 영상을 생성하게 하는 작업을 opus 5.5 high fast로 진행시키자. — 2026-10-24 요청

> V4와 병렬로 진행가능하면 brag 영상 작업시작하자. — 2026-10-24

허브가 물은 두 가지에는 "모두 권장방식대로하자"라고 답하셨습니다. 그래서 완료 기준은 다음과 같습니다.
- 길이는 v4와 같은 90~105초이고, v4의 메시지를 모두 담습니다. 연출은 brag 규칙(첫 2초 훅, 박자에 맞춘 컷, 제대로 섞은 음악)을 따릅니다.
- 소리는 음악과 효과음만 넣고 내레이션은 넣지 않습니다. 메시지는 화면 문구가 전합니다.
- 1920×1080, 30fps, 스테레오입니다. brag 방식대로 대표 화면(포스터)을 넣습니다. 내부 검토용이며, 소리가 있는 판은 이 영상뿐입니다.

## 2. 수행한 것

1. brag 저장소의 `brag-slim` 스킬을 이 PC의 사용자 스킬로 설치하고, 연출 톤 "polished"(절제된 정돈형)와 길이 100.8초로 불러 썼습니다. brag의 다른 스킬과 파일은 저장소에 넣지 않았습니다.
2. brag 절차대로 먼저 제작 계획(brag-plan)을 썼습니다. 내용은 각도, 훅, 강조점, 음악 템포, 박자 단위 장면표입니다. 템포는 100 BPM으로 정했습니다. 한 박이 0.6초(18프레임), 한 마디가 2.4초여서 모든 박이 정확히 프레임에 떨어집니다. 영상은 42마디입니다.
3. v4 장면 코드를 복사해 시간표만 바꿨습니다.
   - 시작 로고를 맨 앞에서 빼고, GAID가 도구를 모으는 장면 뒤의 "공개" 자리(14.4초)로 옮겼습니다. 영상은 연구자의 일로 바로 시작합니다.
   - 배경의 세 단계, 연구 순환, 시연 여섯 장, Second brain, 마무리가 모두 마디선에서 바뀝니다. 장면 사이는 한쪽이 사라진 뒤 다음이 나타나게 해, 복잡한 화면 두 개가 겹쳐 흐려지지 않게 했습니다.
   - 시연 촬영본은 컷이 박에 떨어지도록 장면마다 0.2~0.8초 줄이거나, 마지막 화면을 그만큼 더 보여 줍니다.
4. 음악과 효과음을 코드로 합성했습니다. 효과음은 장면 코드가 내보내는 사건 시각(카드 등장, GAID 패널 도착, 장 전환, 이름표 등장 등 82개)에 맞춰 16분음표 격자에 놓습니다. 효과음의 음높이는 그 마디의 화음에서 고르고, 음악과 같은 잔향을 씁니다.
5. 장면별 정지 화면과 전환 직전·직후 화면을 보고 겹침과 빈 화면을 확인한 뒤 최종 영상을 렌더했습니다. 첫 프레임은 brag 방식대로 대표 화면으로 바꿨습니다.

v4와 다른 점은 세 가지입니다.
- 시작 로고(v4 0–4초)가 14.4초로 옮겨졌습니다. 그래서 첫 화면이 바로 연구자의 일입니다.
- 장면 길이가 박자 단위로 바뀌어 전체가 103.0초에서 100.8초가 되었습니다. 줄인 곳은 연구 순환(8.2초 → 7.2초), Second brain(7.8초 → 7.2초), 시연 일부 장면입니다. 화면 문구와 이름표는 하나도 빼지 않았습니다.
- 음악과 효과음이 들어갔습니다.

함께 나온 brag 결과물은 공유 문구 한 단락("자료를 찾고, 논문을 읽고, 코드를 짜는 사이 흩어져 있던 스킬과 도구를 GAID가 한곳에 모았습니다. …")과 대표 화면 그림입니다.

## 5. 한계

- 소리를 귀로 확인하지 못했습니다. 이 작업 환경에서는 소리를 재생해 들을 수 없습니다. 그래서 음량, 최고 음압, 주파수 대역별 세기, 박자 정렬, 동기만 수치로 확인했습니다. 음색이 어색하거나 효과음이 거슬리는지는 검토하실 때 들어 봐 주셔야 합니다.
- 음악은 이 저장소의 코드가 발진기와 잡음으로 직접 만든 것입니다. 녹음된 음원이나 샘플, 다른 곡은 쓰지 않았습니다. 그래서 저작권이 걸린 소리는 없지만, 전문 작곡가의 곡보다 단순합니다.
- brag는 15~25초 영상을 권합니다. 이번에는 사용자 결정에 따라 v4와 같은 길이(100.8초)로 만들었고, 나머지 brag 규칙만 따랐습니다.
- 내부 검토용입니다. 기관 로고의 외부 공개 승인이 아직 나지 않았습니다(gaid-release-proof#2).
- 설명 그림 장면: 배경(0–14.4초), 로고, 연구 순환(19.2–26.4초), KIGAM Second brain(88.8–96.0초)은 실제 화면이 아닌 설명 그림입니다. 배경의 스킬과 도구 이름은 실제 이름이고, 개수나 시간 같은 수치는 넣지 않았습니다.
- v4 보고서에 적은 한계가 그대로 남습니다. 허브 공유 장이 분석 장보다 먼저 나와서 분석 장의 시작 창에는 "version 0.1.0"이 보입니다. 분석 결과는 수렴이나 광체 복원을 주장하지 않는 "검토 전" 노트입니다.
