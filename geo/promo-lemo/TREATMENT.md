# Treatment: GAID promo, lemo edition (Dark Tech Keynote)

Task `gaid-promo-video-v4-lemo`. Style: lemo-opuscar `styles/dark-keynote/STYLE.md` (commit 3961ddb). Same messages as v4
(`geo/promo/`, report `reports/2026-10-24-gaid-promo-video-v4/`), about 100 s, 1920×1080, 30 fps (the style's own rate is 24;
the GAID takes are 30 fps), music and sound effects only, no narration, no subtitles track: the on-screen copy carries the message.

## 1. Brief as understood

- Subject: GAID, the AI agent research platform for geoscientists, in two parts: GAID 허브 (Workflows made from papers, shared and
  improved) and GAID 시스템 (my library, analysis, research notes).
- Must keep: v4's message order and copy (background → cycle → six demo chapters on real takes → second brain → closing);
  visible names "AI agent"/"GAID"; no invented numbers; no "개념도" corner labels; brand blue as the one accent; Pretendard.
- Standing user rule (2026-10-23): real takes play whole at one scale, never zoomed or scrolled. The camera moves only on the
  stage between takes and in the graphic scenes.

## 2. Three candidate structures

1. **Disorder → one press → the grid → the cycle (chosen).** The style's own arc: generated mess, one decisive action, order and
   space. It is v4's background argument in the medium's grammar, so the background becomes the hook instead of a preamble.
2. **A countdown checklist.** Six research steps tick off as UI moments ending on "다음 연구로". Clear, but turns the film into a
   feature list again, which the user rejected for v3.
3. **A zoom ladder.** One cursor → one window → one researcher's ring → many rings (the institute). Strong ending but the demo
   would need zooms into the takes, which the standing rule forbids.

Chosen: 1, with the zoom ladder's last rung (pull-back to many rings) kept for the second-brain scene.

## 3. Logline and arc

A geoscientist's papers, data, code and a scattered crowd of skills and agent tools pile up on a dark screen until one blue
press snaps them into GAID; the research then runs once around the cycle in the real app and the camera pulls back to show
every researcher's cycle feeding one institute.

- Setup (0–11 s): too much, everywhere, out of reach.
- Turn (11–21 s): freeze, silence, one press; everything lands in one grid; GAID's name.
- Development (21–89 s): the cycle, then the real app chapter by chapter, each opening with its purpose.
- Ending (89–102 s): the rings multiply; put-away to one lit tile, the mark.

## 4. Benchmark (grammar only)

- Product keynotes on a black stage: one line per screen, light as the reveal, an accent reserved for the product.
  Learn: negative space, one focal element per shot. Do not take: any layout, device, typeface, melody or logo.
- Steve Reich's process music (additive build, one chord everything lands on). Learn: music as a visible process. Do not take:
  any melody.

## 6. Beat sheet and cue map

Tempo 120 bpm (beat 0.5 s = 15 frames, bar 2 s). Every section start, snap landing, chapter start and tag lands on a beat
(chapter starts are quantised by stretching the collapse/expand transition to the next beat).

| Section | Time (s) | Music state | Key hits |
|---|---|---|---|
| Hook / work | 0–5.6 | scattered: detuned (±15–40 cents) marimba, xylophone, mbira, woodblock plinks, random pans, density rising with spawns; low sine pulse | every spawn = one plink |
| Scattered tools | 5.6–11.0 | same family, more detuned, coil whine rising, reach lines with a falling sine | card scatter, missed reaches |
| Freeze | 11.0–11.6 | digital zero (silence 1) | — |
| Press + snap | 11.6–16.6 | felt mallet + sine drop on the press; landings = vibraphone notes of one mode (D Lydian), centred; ends on one chord at 16.0 | press 11.6, chord 16.0 |
| Title | 16.6–21.0 | bowed vibraphone pad chord, light-sweep shimmer (J-cut: shimmer starts 0.3 s before the light) | lockup 17.0 |
| Cycle | 21.0–28.0 | additive process: marimba ostinato, one note added per bar; glockenspiel tick per station | stations, version tick |
| Demo | 28–89 | steady process: marimba ostinato + soft sine bass + shaker; chord change at each chapter start; tags = glass taps in key; analysis chapter divides the beat (16th shaker); notes chapter drops the shaker (breath); return-to-library resolves | chapter starts, tags |
| Near-silence | 88.6–89.0 | −60 dB room only (silence 2) | first sound after it: low bell + chord |
| Second brain | 89–97 | build: each new ring a shimmer note in the same mode; bowed pad | ring spawns |
| Ending | 97–102 | put-away: one note removed per beat until one glockenspiel note on the lit tile; then zero | final tile ~100.5 |
